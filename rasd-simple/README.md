# رَصد — النسخة المبسطة

## المتطلبات
- Node.js 20 أو أحدث
- اتصال بالإنترنت لإرسال Telegram

## التشغيل
1. فك ضغط المشروع وافتح المجلد في Terminal.
2. نفّذ: `npm install`
3. انسخ `.env.example` إلى ملف باسم `.env`.
4. ضع رمز بوت Telegram الجديد ومعرّف المحادثة في `.env` (لا ترسلهما لأحد).
5. افتح Telegram واضغط Start للبوت أول مرة.
6. نفّذ: `npm start`
7. افتح `http://localhost:3000`

## ما الذي يتضمنه؟
- خمسة نماذج: المبيعات، المصروفات، التالف والهدر، الصيانة، تقييم الموظفين.
- حفظ دائم في SQLite داخل `data/reports.sqlite`.
- إرسال التقارير إلى Telegram، وإرفاق صورة أو PDF.
- أرشيف آخر 100 تقرير وإعادة إرسال التقرير نفسه دون إنشاء نسخة جديدة.
- اختبار اتصال Telegram.

## تنبيه أمني مهم
إذا سبق أن شاركت رمز البوت في محادثة أو مكان عام، ألغِه من BotFather وأنشئ رمزًا جديدًا. لا تضع الرمز في ملفات الواجهة أو ترسله في المحادثات. احتفظ بملف `.env` خاصًا ولا تشاركه.
هذه نسخة أولية مبسطة للاستخدام المحلي. قبل نشرها على الإنترنت أضف تسجيل دخول وصلاحيات وHTTPS ونسخًا احتياطيًا للبيانات، وحدّث الحزم دوريًا.
